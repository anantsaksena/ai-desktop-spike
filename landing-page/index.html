How it protects your documents

💻

The AI runs on your machine

A bundled llama.cpp server runs the model on your CPU. Your documents and questions never leave the computer. No cloud API, no telemetry, no account.

🔒

Encrypted at rest

Extracted text and the search index live in a SQLCipher 4 database (AES-256, per-page HMAC). The key is kept in your OS keychain (or a private 0600 key file if there's no keychain), never inside the database.

📑

Answers show their sources

Every answer lists the pages it used. Click one to read the exact passage, so you can check the answer instead of trusting it.

What it does not do (yet)

  • One download, once: the first launch offers to download the AI model (about 1 GB, SHA-256 verified). After that it works with Wi-Fi off.
  • Keyword search today: passages are found with full-text search (BM25). Semantic search is planned.
  • Text PDFs only: scanned documents need OCR, which isn't built in yet.
  • Small model: a 1.5B model is fast on a laptop but can be wrong. That's why the sources are always shown.

Install v0.1.1

Ubuntu / Debian / Mint

wget https://github.com/anantsaksena/ai-desktop-spike/releases/download/v0.1.1/ai-desktop-spike_0.1.1_amd64.deb
sudo apt install ./ai-desktop-spike_0.1.1_amd64.deb

Any distro (AppImage)

wget https://github.com/anantsaksena/ai-desktop-spike/releases/download/v0.1.1/ai-desktop-spike_0.1.1_amd64.AppImage
chmod +x ai-desktop-spike_0.1.1_amd64.AppImage
./ai-desktop-spike_0.1.1_amd64.AppImage

x86-64 with AVX2 (most PCs from 2015 on), 4 GB RAM. Verify downloads against SHA256SUMS. AUR, Snap and Flatpak packages are planned. macOS and Windows will follow.
